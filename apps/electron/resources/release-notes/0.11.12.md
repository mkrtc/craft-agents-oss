# v0.11.12 — Runtime Lifecycle Hotfix

This file accumulates release notes for the next unreleased version. PRs that add user-visible behavior should append a bullet to the relevant section here. Versioned files (`X.Y.Z.md`) are owned by the release skill — never create them in feature commits.

## Features

## Improvements

- **Bounded session runtimes** — Inactive session backends are now reclaimed with a configurable idle timeout and retained-runtime cap, while active permissions, tools, compaction, and background work remain protected.
- **Reliable process cleanup** — Agent, model, MCP, pool, and server resources now use awaited, idempotent teardown across refresh, deletion, cancellation, failure, and application shutdown.

## Bug Fixes

- **Prevented runaway memory growth** — Fixed retained Pi, Claude, Kubernetes, SSH, and other MCP subprocess trees accumulating after sessions became inactive.
- **Recovered stalled chats** — Backend crashes and inactivity timeouts now retire the exact failed runtime, clear the thinking state once, and preserve retryable session state without unsafe automatic replay.
- **Fixed shutdown races** — Repeated headless/server shutdown signals now share one cleanup operation and cannot exit before subprocess teardown finishes.
