# v0.11.7 — macOS Updater Reliability

This hotfix improves the macOS update install path after reports that a downloaded update could show a restart button but fail to apply after restart.

## Features

- None.

## Improvements

- **Validated macOS update installs** — The updater no longer marks cached files as ready to install until `electron-updater` has validated the download. If the UI reaches an install-ready state without an internal validated update, Craft Agents now re-drives the download before calling `quitAndInstall()` and reports a clear error instead of appearing to do nothing.
- **macOS updater diagnostics** — Install failures from the native macOS menu are now logged instead of surfacing as silent unhandled failures.
- **Intel Mac release assets** — Release builds now publish macOS x64 DMG/ZIP artifacts for manual Intel Mac installs without overwriting the Apple Silicon auto-update manifest.

## Bug Fixes

- **Restart and update reliability on macOS** — Fixed a cache-state path where the app could show `Restart and update` based on files in the updater cache even though the updater had not validated an installable pending update.

## Breaking Changes

- None.
