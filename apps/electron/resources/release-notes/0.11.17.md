# v0.11.17 — Manual Labels and Provider Handoffs

## Features

- **Manual hierarchical labels** — Create root labels and nested sublabels directly from the sidebar, composer, or Labels settings, with parent breadcrumbs, colors, and typed values—no AI model required.
- **Continue with another provider** — Move an ongoing conversation to a new chat on another authenticated connection or model. Craft carries over a summarized handoff and workspace context while preserving the original conversation.
