# v0.11.6 — Agent Status Control

This patch release lets agents update Craft session workflow statuses directly while preserving a conservative permission boundary for cross-session orchestration.

## Features

- None.

## Improvements

- **Agent-controlled session statuses** — Agents can now set their own session to any configured status, including closed states such as `done` or `cancelled`, so completed work can accurately update the board and trigger status-change automations. Cross-session status changes are restricted to sessions labeled `orchestrator`, and calls are refused when that role cannot be verified.
