# v0.11.4 — Fork Release: macOS Updater Fix

This patch release fixes the macOS restart-to-update lifecycle so downloaded updates can install correctly instead of being interrupted by app quit cleanup.

## Features

- None.

## Improvements

- None.

## Bug Fixes

- **macOS update install/restart** — Update installation now runs critical pre-update cleanup before handing off to `electron-updater`, avoids canceling updater-owned quits, and preserves `autoInstallOnAppQuit` by removing the forced `app.exit(0)` quit path.

- None.
