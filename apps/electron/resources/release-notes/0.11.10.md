# v0.11.10 — Whip Interrupt

## Features

- **Whip interrupt easter egg** — Added a Whip button next to the chat input: arm it while an agent is processing, keep the animated leather whip active, left-click the chat for a playful strike, or right-click to crack the whip and interrupt the running agent.

## Improvements

- **Whip animation and controls** — Added rope-style physics, a staged backswing-and-strike animation, smoothed pointer tracking, an explicit cancel control, and reduced-motion fallback behavior.
