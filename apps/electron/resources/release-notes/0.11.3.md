# v0.11.3 — Fork Release: Kanban Task Tools

This patch release adds agent-facing Kanban task tools and per-node skill/model guidance so orchestrators can coordinate board-backed work through task specs.

## Features

- **Kanban task tools for agents** — Agents can now validate, create, run, inspect, list, and collect results from Kanban task specs, with per-node skills and current-session callback integration keeping board-launched work tied to the right orchestrator.

## Improvements

- **Task path safety** — Task slugs, run IDs, and node output paths are validated before storage access so agent-facing task tools cannot traverse outside the workspace task directory.
- **Dynamic model selection guidance** — Task generation and local workflow skills now guide orchestrators to choose task/node models dynamically from available Craft model and connection metadata, optionally using current benchmark references such as the Artificial Analysis Coding Agent Index.
